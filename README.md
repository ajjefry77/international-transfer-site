# International Transfer Site | سایت انتقال بین‌المللی وجه

## 🇬🇧 English Description
A modern, responsive, and secure web application designed for international money transfer services. Built with React and TypeScript, it features multi-language support (i18n), interactive mapping (Leaflet/OpenLayers), currency formatting, and seamless integration with a PHP backend.

## 🇮🇷 توضیحات فارسی
یک وب‌اپلیکیشن مدرن، واکنش‌گرا و امن برای خدمات انتقال وجه بین‌المللی. این پروژه با استفاده از React و TypeScript توسعه داده شده و شامل پشتیبانی از چند زبان (i18n)، نقشه‌های تعاملی (Leaflet/OpenLayers)، فرمت‌دهی ارز و یکپارچگی کامل با بک‌اند PHP است.

## 🇬🇧 Features
- 🌍 Multi-language support (Persian, English, etc.)
- 💱 Real-time currency input and formatting
- 🗺️ Interactive maps for branch/agent location tracking
- 📱 Fully responsive design with Tailwind CSS and Mantine UI
- 🔒 Secure API communication with PHP backend

## 🇮🇷 ویژگی‌ها
- 🌍 پشتیبانی از چند زبان (فارسی، انگلیسی و ...)
- 💱 ورودی و فرمت‌دهی بلادرنگ ارز
- 🗺️ نقشه‌های تعاملی برای ردیابی موقعیت شعب یا نمایندگان
- 📱 طراحی کاملاً واکنش‌گرا با Tailwind CSS و Mantine UI
- 🔒 ارتباط امن API با بک‌اند PHP

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Mantine, Material-UI, Framer Motion
- **Mapping:** Leaflet, OpenLayers
- **Backend:** PHP
- **Tools:** Axios, i18next, React Router

```bash
# Clone the repository
git clone https://github.com/ajjefry77/international-transfer-site.git
